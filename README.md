# CNM OpModeHandlingInterfaces lib

## Overview

This is a TwinCAT 3 library project for operation mode handling interfaces.

## Version Information

- **Version:** 0.1.1.0
- **Release Date:** 2025

## Documentation Location

You will find the detailed library documentation at the [cinnamon docs](https://static.ekvip.de/docs/CNM_OpmodeHandlingInterfaces/0.1.1.0/)

## Purpose

This library defines interfaces for the operation mode handling mechanism. They are designed to implement the hierarichal composition pattern.
